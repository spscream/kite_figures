# kite_figures

Фигуры соревнований по спортивному кайту (ISK Compulsories Book): каталог, схемы из своих данных, ссылки на официальные правила.

Статический сайт на Next.js: данные фигур лежат файлами в `data/figures/`, сборка превращает их в папку `out/`.

```sh
npm ci
npm run dev     # локально, http://localhost:3000
npm run gate    # линт, типы, тесты, сборка и проверка собранного
npm run build   # готовая статика в out/
```
